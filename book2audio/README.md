# book2audio

Suprasuta Book2Audio, rewritten in TypeScript.

- `book2audio-core-engine/`  shared engine (text, books, voice, audiobook build)
- `book2audio-web/`          Vercel web app
- `book2audio-windows/`      Windows app
- `samples/`                 listening samples

The original Python version lives next to this folder as `book2audio-python` and stays as the reference until this one matches it.

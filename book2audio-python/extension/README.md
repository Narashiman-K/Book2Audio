# Suprasūtā Read Aloud (browser extension)

Reads the page you are on with your local Book2Audio voice (Kokoro), highlighting the sentence and word as it goes.

## Install (Edge, Chrome, Brave)
1. Start the Studio (`studio.bat`).
2. Open `edge://extensions` (or `chrome://extensions`), turn on **Developer mode**.
3. **Load unpacked**, choose this `extension` folder.
4. In the Studio open **Web to Audio**, press **Connect extension**. (Or paste the address and token in the extension's settings.)

## Use
- Click the extension button, then **Read this page**.
- Select text on any page and press **Read from here** (or right-click > Read aloud from here).
- Player: previous / pause / next sentence, speed. `Esc` closes it.
- **Send page to Studio as audio file** makes an MP3 narration that appears in Web to Audio.

Nothing leaves your computer: the extension only talks to 127.0.0.1.
